Dokumentasi Asset Karyawan

Tujuh belas fitur dan satu dokumen infrastruktur penyimpanan foto yang mengatur perjalanan asset — di tangan karyawan (diterima, dipakai, dikembalikan), di ruangan (dialokasikan, diupgrade, dan diretur lewat PIC), dan di gudang (dirawat, diperbaiki, diklaim, dihapus). Setiap dokumen disusun dari source code API (Lumen) dan MOBILE (Flutter) dengan 48 bagian yang sama.
